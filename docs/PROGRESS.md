# Revision 2.0

Completed the Java/Spring Boot migration: controllers, typed input validation, signed sessions, persistence, jobs, SerpApi/Open-Meteo/Groq integration, scheduling, budgets, weather adaptation, trip extensions, postponement, versions and exports. React uses Java through the same API routes. Removed Express and the TypeScript backend services.

The delivered archive includes Java source, Maven Wrapper, executable JAR, React source/build and setup instructions. Production SerpApi/Groq verification still requires the user's own credentials. Deployment/database/accounts/distributed microservices remain separate future work.
